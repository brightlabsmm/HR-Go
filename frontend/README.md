# HR Go frontend

Vite + React + TypeScript app using Tailwind CSS, shadcn/ui, and Yarn.

## Scripts

```bash
yarn install
yarn dev
yarn build
yarn lint
yarn typecheck
```

## Adding shadcn/ui components

```bash
yarn shadcn add button
```
